# 小米手环 10 / 8 NFC Codex 额度

在电脑和安卓手机查看 **Codex 5 小时额度、周额度、重置时间和当前任务状态**。小米手环 10 使用独立
「Codex额度」快应用；小米手环 8 NFC 可通过系统通知兼容模式查看配额摘要和任务提醒。

## 它能做什么

- 在手机和小米手环 10 快应用中查看完整额度看板。
- 在小米手环 8 NFC 的原生通知列表查看低频配额摘要。
- 查看 ChatGPT Windows 客户端中的任务状态：
  `处理中`、`需要授权`、`等待查看`。
- 在任务需要授权或等待查看时向手机、手环发送提醒。
- 数据只在你的电脑、手机和手环之间传输，不经过本项目的云服务器。

## 使用前准备

你需要：

- 一台 Windows 10 或 Windows 11 电脑；
- 已登录并正常使用的 ChatGPT Windows 客户端；
- 一台安卓 8.0 或更高版本的手机；
- 小米手环 10，或用于通知兼容的小米手环 8 NFC；
- 手环 8 NFC 不运行本项目的 RPK，也不提供自定义额度页面；它通过小米运动健康转发 Android 通知，当前路径已完成真机验收；
- 其他版本的小米手环暂未完成真机验证；
- 手机中已安装「小米运动健康」，并已连接手环；
- 手机和电脑连接同一个局域网。

## 安装和连接

### 第一步：运行 Windows 便携版

1. 下载并解压 `CodexQuota-0.6.0-Windows-x64-portable.zip`，保持其中的 `CodexQuota.exe` 和 `libunwind.dll` 在同一目录。
2. 运行 `CodexQuota.exe`；程序会出现在任务栏右下角的通知区域。
3. 右击托盘图标打开配对信息，继续完成手机扫码配对。
4. 重启 ChatGPT，在「ChatGPT → 设置 → 钩子 → 信任全部钩子」中确认以下四项已开启：
   `PreToolUse`、`PermissionRequest`、`UserPromptSubmit`、`Stop`。

### 第二步：安装安卓应用

1. 在手机上安装 `CodexQuota-0.6.0.apk`。
2. 打开「小米运动健康」，确认手环仍然在线。
3. 打开手机上的「Codex额度」。
4. 建议在手机系统中为 Codex额度开启：
   - 自启动；
   - 应用加锁；
   - 电池使用不受限制。

这些设置能提高锁屏和后台同步的稳定性，但安卓系统仍可能在内存不足时结束应用。

### 第三步：连接手机和电脑

1. 确认手机和电脑连接同一个局域网。
2. 右键 Windows 通知区域中的「Codex额度」，选择「显示配对二维码…」。
3. 在手机「Codex额度 → 设置」中点击「扫码连接电脑」。
4. 扫描电脑上的二维码并按提示完成配对。
5. 配对成功后，手机首页会显示电脑“已连接”，额度和任务会自动同步。

二维码只在短时间内有效。过期后，从 Windows 通知区域重新生成即可，不需要手动输入电脑地址或配对码。

### 第四步：连接手环

#### 小米手环 10：安装手环应用

AstroBox 只在安装或升级手环应用时临时使用，不参与日常同步。

1. 临时打开 [AstroBox](https://astrobox.online/downloads/)。
2. 进入已连接的小米手环 10 设备页面。
3. 打开「快应用数量」右上角的设置。
4. 点击 `+`，导入 `com.codex.quota.android.release.0.6.0.rpk`。
5. 等待安装动画结束。
6. 安装完成后退出 AstroBox，重新确认「小米运动健康」仍显示手环已连接。
7. 在手机「Codex额度 → 设置」中点击「检查手环 10 应用连接」，按系统提示授权。
8. 打开手环上的「Codex额度」，数据通常会在几秒内出现。

#### 小米手环 8 NFC：开启通知兼容

手环 8 NFC 不安装 RPK，也不需要 AstroBox。它通过「小米运动健康」把 Android 系统通知转发到手环，当前路径已完成真机验收：

1. 保持「小米运动健康」与手环连接。
2. 允许手机「Codex额度」发送系统通知。
3. 在「小米运动健康」的手环通知/应用通知设置中允许「Codex额度」；不同版本的菜单名称可能略有不同。
4. 打开「Codex额度 → 设置 → 小米手环 8 NFC」，开启“通知兼容模式”。
5. 点击“立即发送配额”，再到手环的通知列表查看摘要。

如果希望手机亮屏时也能转发，请在小米运动健康中关闭“仅在手机锁屏时通知”；否则该选项开启时，亮屏状态下可能不会把通知转发到手环。

兼容模式会在手机通知栏保留一条可划掉的配额通知，这是小米运动健康读取并转发它的必要条件。自动更新只在首次取得
有效数据、额度向下跨过 75/50/25/10 阈值或重置周期变化时发送，不会把每次同步都变成通知。

## 日常使用

平时只需要保持以下程序正常运行：

- Windows 通知区域中的 Codex额度；
- 安卓手机上的 Codex额度；
- 小米运动健康。

电脑端可右击通知区域中的 Codex额度图标，打开“连接与诊断…”查看 Windows 服务、Android 手机和额度源状态。Android 手机状态分别表示：尚未配对、配对凭据仍在但当前离线、当前已建立在线连接。

AstroBox 可以退出。

手机不需要登录 OpenAI，也不需要一直开启 VPN 或代理。它只通过可信局域网连接自己的 Windows 程序，再由
「小米运动健康」连接手环；如果 VPN 会接管局域网流量，请把电脑私网地址设为直连。

状态含义：

| 状态 | 含义 |
| --- | --- |
| 已同步 | 最近一次额度确认仍然有效 |
| 缓存 | 显示的是上一次可信数据，不是实时数据 |
| 离线 | 手机无法连接电脑或手环 |
| 处理中 | ChatGPT 正在处理任务 |
| 需要授权 | ChatGPT 正在等待你确认操作 |
| 等待查看 | 当前一轮已经停下，等待你查看结果；不代表成功或失败 |

如果上游暂时没有提供 5 小时额度，手机和手环会显示 `-- / 暂无数据`，不会猜测额度。

## 检查更新

手机「Codex额度 → 设置 → 检查更新」会检查本项目公开的 GitHub Release：

- 已是最新版时会显示提示；
- 有新版本时会先显示版本和更新说明；
- 只有你点击“前往下载”后才会打开 GitHub；
- 不会自动下载或安装。

## 常见问题

### 手机扫码后连不上电脑

- 确认手机和电脑在同一个局域网；两端都能上网不代表在同一个局域网。
- 不要使用访客 Wi-Fi、公共 Wi-Fi 或启用了设备隔离的网络。
- 首次启动时，允许 Codex额度通过 Windows 防火墙的专用网络。
- 如果启用了 VPN 或代理，让手机访问电脑私网地址时绕过 VPN。
- 在 Windows 通知区域打开「连接与诊断…」查看具体状态。
- 其中“Android 手机”会分别显示“未配对”“已配对 · 离线”或“已配对 · 在线”；离线不代表配对记录丢失，手机恢复后台联网后会自动重连。

### 手机锁屏后显示缓存

在手机系统中为 Codex额度开启自启动、应用加锁和电池使用不受限制。不同品牌手机的设置名称可能略有不同。

### 小米手环 10 显示离线或不更新

1. 确认「小米运动健康」仍显示手环已连接。
2. 完全退出 AstroBox，避免它继续占用手环连接。
3. 确认手机、手环安装的是同一版本。
4. 在手机 Codex额度的设置中点击「检查手环 10 应用连接」。

### 小米手环 8 NFC 收不到通知

1. 先确认手机通知栏能看到「Codex额度」通知；看不到时检查 Android 通知权限和对应通知渠道。
2. 在「小米运动健康」中确认已允许转发「Codex额度」的应用通知。
3. 确认手环没有开启会屏蔽通知的勿扰模式，并保持与小米运动健康连接。
4. 回到「Codex额度 → 设置 → 小米手环 8 NFC」点击“立即发送配额”复测。

任务的 `Stop` 通知会显示为“等待查看”，只表示本轮已停下，不代表任务已经完成。

### 任务状态不可用

1. 在 Windows 通知区域选择「安装/修复任务 Hook」。
2. 重启 ChatGPT。
3. 打开「ChatGPT → 设置 → 钩子 → 信任全部钩子」。
4. 确认四项 Hook 均已开启，然后新建一个任务测试。

### 5 小时额度显示 `--`

这表示当前上游数据中还没有 5 小时额度，不是同步失败。周额度、任务和手环连接仍可正常使用；上游提供数据后会自动显示。

### 重装后可用重置次数显示 `--`

打开 ChatGPT 的使用量页面，展开额度重置相关内容并等待加载完成，然后在 Windows 通知区域选择「刷新当前状态」。

## 隐私说明

- 不读取或传输你的提示词、回复、命令、文件路径、终端输出或完整日志。
- 不读取 ChatGPT Cookie 或登录密码。
- Windows 只在本机使用现有 Codex 访问令牌查询官方额度；令牌不会写入项目日志、诊断、手机或手环。
- 手机与电脑通过加密连接在局域网中同步。
- 手机不会调用 OpenAI 接口；手环 8 NFC 只接收小米运动健康转发的脱敏通知文字。
- 不包含广告、遥测或自动崩溃上报。
- 请勿把 Windows 同步端口暴露到公网。

更多说明见 [安全说明](docs/security.md)。

## 卸载

- Windows：在「设置 → 应用 → 已安装的应用」中卸载 Codex额度。
- 安卓手机：直接卸载 Codex额度。
- 小米手环 10：通过 AstroBox 卸载 Codex额度。
- 小米手环 8 NFC：没有本项目手环应用；在安卓 App 中关闭兼容模式，或在小米运动健康中关闭通知转发即可。
