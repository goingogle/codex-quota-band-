# 真机验收摘要

本文件是公开的验收结论，不记录个人设备编号、局域网信息、临时路径或逐次试装过程。

## 0.6.0 已确认项目（小米手环 10）

- Windows 程序可安装、启动并显示托盘入口。
- 手机可以扫码配对并同步额度、任务和连接状态。
- 缺失 5 小时额度时，手机和手环显示 `-- / 暂无数据`，不会猜测数据。
- 有 5 小时额度时，手机与手环均可正确显示百分比、重置时间和颜色。
- 手机锁屏后会明确降级为缓存；开启自启动和电池不受限后可提高后台同步稳定性。
- 手环可以接收额度摘要和任务提醒；首页与任务页可通过原生纵向 swiper 切换。
- 周额度进度条与百分比使用一致的红 / 黄 / 绿状态色。
- 设置页的检查更新只在用户确认后打开 GitHub，不会自动下载或安装。

## 仍需理解的系统限制

- 安卓系统可能结束后台应用，因此不能承诺同步或通知必达。
- 手环日常连接由「小米运动健康」保持；AstroBox 仅用于安装或升级 RPK。
- 手机和电脑需要处于同一个可信局域网。

## 小米手环 8 NFC 待验收

下面项目目前都是验收清单，不代表已经通过：

- [ ] 「小米运动健康」保持手环连接，并在“应用通知”中允许「Codex额度」。
- [ ] Android「Codex额度 → 设置」开启“通知兼容模式”后，“立即发送配额”会在手机和手环通知列表显示相同的真实摘要。
- [ ] 缺失或待同步的 5 小时额度显示“暂无数据”或“待同步”，不使用残留值或猜测百分比。
- [ ] 自动配额通知只在首次有效数据、向下跨过 75/50/25/10 阈值或重置周期变化时出现，普通 45 秒刷新不重复提醒。
- [ ] `PermissionRequest` 到达手环时显示“需要授权”，`Stop` 显示“等待查看”，`Running` 不产生提醒。
- [ ] 手机关闭 VPN/代理后，仍可通过同一可信局域网接收 Windows 数据并转发通知；手机不访问 OpenAI。
- [ ] 通知可从手机通知栏划掉，不出现由本项目创建的常驻前台服务通知。
- [ ] 锁屏和短时后台场景按设置送达；同时记录 Android 杀死进程后不保证即时通知的限制。

小米手环 10 的 `0.6.0` 已通过上述原有真机验收；手环 8 NFC 兼容模式尚未通过。提交、推送和发布仍需要维护者单独授权。
